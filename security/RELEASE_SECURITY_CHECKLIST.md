# Release Security Checklist
Version: 1.0

公開前に必ず実施する。

## 1. 秘密情報
- [ ] APIキー・秘密鍵・トークンがコードに直書きされていない
- [ ] .env に秘密情報を置く場合、Git対象外になっている
- [ ] .env.example に実値が入っていない
- [ ] ログに秘密情報が出ない

## 2. 個人情報・プライバシー
- [ ] 収集するデータを把握している
- [ ] 不要な個人情報を収集していない
- [ ] 外部サービスへ送るデータを把握している
- [ ] プライバシーポリシーと実装内容が一致している

## 3. 認証・認可
- [ ] ログイン機能の有無を確認した
- [ ] 他ユーザーのデータへアクセスできない
- [ ] 管理者権限などをクライアント側だけで判定していない

## 4. API・通信
- [ ] 外部通信先を把握している
- [ ] 原則HTTPSを使用している
- [ ] APIキーなどがクライアントから露出していない
- [ ] エラー表示に内部情報を出しすぎていない

## 5. DB・端末保存
- [ ] 保存するデータを把握している
- [ ] 不要なデータを保存していない
- [ ] 機密データの保存方法を確認した
- [ ] クラウドDB使用時はアクセス権限を確認した

## 6. 入力値
- [ ] ユーザー入力を検証している
- [ ] URL・ファイル・画像等の外部入力を検証している
- [ ] 想定外入力で危険な処理やクラッシュが起きない

## 7. Dependency・SDK
- [ ] 不要なdependencyがない
- [ ] 既知の重大な脆弱性を確認した
- [ ] 分析・広告・課金等のSDKを把握している
- [ ] 外部SDKが収集するデータを把握している

## 8. 端末権限
- [ ] 使用している権限を把握している
- [ ] 不要なカメラ・マイク・位置情報等の権限がない
- [ ] 権限要求の説明文が実装と一致している

## 9. 本番設定
- [ ] デバッグ専用機能が残っていない
- [ ] テスト用アカウント・URL・キーが残っていない
- [ ] 本番環境設定になっている

## 10. ストア申告
- [ ] App Store / Google Playのプライバシー申告と実装が一致している
- [ ] 課金内容とストア設定が一致している
- [ ] 対象年齢・子ども向け設定を確認した

## 11. Security Profile
- [ ] SECURITY_PROFILE.mdが現在の実装と一致している
- [ ] リスクレベルを再判定した
- [ ] 未確認項目が残っていない

## 最終判定
- [ ] PASS
- [ ] HOLD
- [ ] STOP
