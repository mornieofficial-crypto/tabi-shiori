# 同期用の中継サーバー

2人の端末のあいだで、**暗号化された旅行データ**を受け渡すだけの小さなサーバーです。
サーバーは内容を読めません(鍵は共有リンクの `#` 以降にだけあり、サーバーへは送られません)。

- `worker.js` … 本番用(Cloudflare Workers + Durable Objects)。**実際の Cloudflare 上では未確認**。
- `node-relay.mjs` … お手本(メモリ上)。テスト用。`node relay/node-relay.mjs` で手元に起動できる。
- プロトコル:`GET/PUT /v1/room/<32桁の16進数>`、書き込みには `X-Token`、版(`rev`)が古いと 409。

## 公開する手順(あなたの操作が必要)

1. Cloudflare のアカウントを作る(無料プランの条件は、公式ページで最新を確認すること)。
2. このフォルダで `npx wrangler login` → `npx wrangler deploy`。
3. 表示された `https://tabi-shiori-relay.<あなたの名前>.workers.dev` を、アプリの「アプリの設定 → 同期サーバー」に入れる。

`wrangler.toml` の `ALLOWED_ORIGIN` は、公開サイトのURLに合わせてあります。変えたときは直してください。

## 守られること・守られないこと

- 守られる:サーバーが漏れても、旅行の中身は読めない。
- 守られない:リンクを他人に転送されると、その人も読み書きできる。サーバーには、更新の時刻や内容の大きさは見える。
- 部屋の名前を知らない人は、部屋を見つけられない(鍵から作った推測できない値)。
